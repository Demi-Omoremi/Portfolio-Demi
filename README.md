# Demi Omoremi | Software Engineer

Live portfolio: https://demi-omoremi.github.io/Portfolio-Demi/

A responsive static portfolio built with HTML, CSS, and JavaScript, featuring project demos, technical skills, education, and certifications.

## Local preview

Run `python -m http.server 5173` in this repository and visit http://localhost:5173.

## Publishing

GitHub Pages publishes the `main` branch from the repository root. Push changes to `index.html`, `styles.css`, `script.js`, or `assets/` to update the site. The `.nojekyll` file enables plain static-file publishing; no build step is required.

The contact form opens the visitor's email client with the composed message. It does not use an email service. Resume PDFs are not included.

Ubuntu's font license is in `assets/Ubuntu-LICENSE.txt`. Skill icons come from SVGL; their source URLs are recorded in `assets/skills/sources.json`.
